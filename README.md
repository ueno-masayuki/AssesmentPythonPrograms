# pygrader — Moodle課題のPythonプログラム自動採点ツール

Moodleの課題に提出されたPythonプログラムを自動評価・採点し、Moodleへそのまま
取り込める形式でフィードバックを出力するツールです。学期中の不定期な課題評価に
対応するため、課題・回答例・ルーブリックをWebUIで登録でき、回答例とルーブリック、
テストケースにはClaude APIによる**提案機能**があります。

## 特徴

- **採点方式**: テストケース実行（客観採点）+ Claude APIによるルーブリック評価・日本語フィードバック生成の併用
- **入力**: Moodleの「すべての提出をダウンロード」zip（展開済みフォルダも可）と「採点ワークシート」CSV
- **出力**:
  1. 評点・フィードバックコメントを記入した**採点ワークシートCSV**（Moodleに一括アップロード可能）
  2. 学生ごとのフィードバックファイルを提出フォルダ名で格納した**フィードバックzip**（Moodleの一括フィードバックファイルアップロード形式）
  3. 教員確認用の**採点レポート（Markdown）**（統計・要確認者・類似提出の検出）
- **WebUI**: 課題の登録・編集、回答例/ルーブリック/テストケースの提案、採点実行、結果ダウンロードまでブラウザで完結
- APIキーがない場合も、テストのみの採点に自動で縮退して動作します

## セットアップ

```bash
pip install -r requirements.txt

# LLM評価・提案機能を使う場合（任意）
export ANTHROPIC_API_KEY=sk-ant-...
```

Python 3.11以上を推奨（開発・テストは3.13）。

## 使い方（WebUI）

```bash
python -m pygrader serve          # http://127.0.0.1:8000/ をブラウザで開く
```

1. **課題を作成** — タイトルを入力して作成し、課題説明（学生に出した問題文）を貼り付ける
2. **テストケース・ルーブリック・回答例を登録** — ✨提案ボタンで Claude に下書きを
   生成させ、確認・修正して保存（提案は編集画面に挿入されるだけで、保存するまで反映されません）
3. **動作確認** — 回答例に全テストを実行し、テストケースの定義ミスを事前に検出
4. **採点を実行** — Moodleからダウンロードした提出zipと採点ワークシートCSVをアップロード
5. **結果をダウンロード** — 記入済みワークシートCSV / フィードバックzip / レポート

### Moodle側の操作

1. 課題画面 →「すべての提出をダウンロード」→ zipを取得
2. 採点操作 →「採点ワークシートをダウンロード」→ CSVを取得
   （課題設定で「オフライン評定ワークシート」を有効にしておく）
3. pygraderで採点後、「採点ワークシートをアップロード」に記入済みCSVを、
   「複数のフィードバックファイルをzipでアップロード」にフィードバックzipを投入
4. 内容を確認して評定を確定

> フィードバックzipのフォルダ名は提出zipと同じ `<氏名>_<参加者ID>_assignsubmission_file_`
> 形式で生成します。お使いのMoodleで初回のみ取り込みを確認してください
> （形式が異なる場合は `pygrader/submissions.py` の `FEEDBACK_FOLDER_SUFFIX` を調整）。

## 使い方（CLI）

WebUIと同じ処理をコマンドラインでも実行できます。

```bash
python -m pygrader init --out kadai3.yaml       # 設定テンプレートを作成
python -m pygrader check --config kadai3.yaml   # 設定を検証し回答例にテスト実行
python -m pygrader grade --config kadai3.yaml \
    --submissions submissions.zip \
    --worksheet grading_worksheet.csv \
    --out out/ [--no-llm] [--no-cache]
```

課題設定の書式は `sample_assignment.yaml`（コメント付き）を参照してください。
WebUIで登録した課題は `data/assignments/<slug>.yaml` に保存され、
`--config data/assignments/<slug>.yaml` としてCLIからも使えます。

## 採点の仕組み

- **テスト点**: 各テストケース（標準入出力 or 関数呼び出し）の合否を重み付き集計
  - 照合モード: `exact` / `trim`（既定: 行末空白と末尾改行を無視）/ `whitespace` / `regex`
- **ルーブリック点**: Claude が課題説明・ルーブリック・回答例・**実際のテスト結果**を
  参照してコードを観点別に採点し、日本語フィードバックを生成
- **最終評点** = (テスト点比率 × 重み + ルーブリック点比率 × 重み) × 最大評点
  （既定 70:30。LLM評価なしのときはテスト100%に自動再正規化）
- 最大評点はワークシートの「最大評点」列 → 課題設定 `max_grade` の順で決定
- LLM評価は内容が同じ限り `.cache/` から再利用され、再採点時のAPI呼び出しを抑えます

## 運用上の注意（重要）

- **学生コードの実行**: 各テストは `python -I`（隔離モード）のサブプロセスを、
  一時ディレクトリ・最小限の環境変数・タイムアウト付きで実行します。ただし
  **完全なサンドボックスではありません**。悪意あるコードはファイル消去や通信を
  行い得るため、信頼できない提出物を扱う場合は仮想マシン等での実行を検討してください。
- **WebUIはローカル専用**: 認証がないため 127.0.0.1 にのみバインドしています。
  公開サーバーには設置しないでください。
- **LLM評価の性質**: ルーブリック点と講評は生成AIによる評価であり、ばらつきが
  あり得ます。最終的な成績は教員がレポート（要確認一覧を含む）で確認してください。
  学生コード内の「指示文」には従わないようプロンプトで対策していますが、万能では
  ありません。
- **文字コード**: 提出ファイルは UTF-8 / Shift_JIS(cp932) / EUC-JP を自動判定します。
  ワークシートCSVは UTF-8(BOM) で読み書きし、Excelで開いても文字化けしません。

## 開発

```bash
python -m pytest tests/            # 単体・結合テスト（LLMはモック不要の縮退経路）
python scripts/make_fixtures.py    # 合成提出物・ワークシートのフィクスチャ再生成
```

ANTHROPIC_API_KEY を設定した環境では、WebUIの提案ボタンと採点時のLLM評価が
実際にAPIを呼び出します。初回は少人数の課題で動作を確認することを推奨します。

## 構成

```
pygrader/   コアライブラリ（設定・提出解析・テスト実行・LLM評価・採点・出力生成）
webapp/     WebUI（FastAPI + Jinja2 + 素のJS）
data/       実行時データ（登録課題YAML・採点結果。gitには含めない）
scripts/    フィクスチャ生成
tests/      pytest一式
```
